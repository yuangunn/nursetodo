# 딱 (ttaak)

> 적고, 딱 체크. 그게 전부.

iOS 앱 [툭(Took)](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982)을 오마주한 안드로이드용 초간단 투두리스트입니다.
**인트라넷(폐쇄망) 안드로이드 폰의 잠금화면**에서 오늘 할 일을 보고, 잠금을 풀지 않고 체크하는 것이 핵심입니다.

## About

**딱**은 iOS 투두 앱 **툭(Took)** 에 바치는 안드로이드 **오마주(homage) 앱**입니다.

툭은 "세상에서 제일 빠른 투두리스트"를 내세워, 다른 투두 앱들이 붙이는 군더더기를 덜어내고
*적고, 바로 체크하는 것*만 남긴 앱입니다. 잠금화면에서 오늘 할 일을 보고 바로 체크하는 경험이 특히 좋았는데,
안드로이드에는 같은 앱이 없었습니다. 그래서 그 철학과 사용 흐름을 안드로이드로 옮겨 보았습니다.

- **이름**: 툭 → 딱. 할 일을 *툭* 적고 *딱* 끝낸다는 의미로, 원작에 대한 존중을 담아 짝이 되는 이름을 붙였습니다.
- **목적**: 인터넷이 막힌 사내(인트라넷) 안드로이드 폰에서, 계정·서버·동기화 없이 잠금화면만으로 하루 할 일을 관리하기 위해 만들었습니다.
- **원작과 다른 점**: 안드로이드에는 iOS의 Live Activity나 잠금화면 위젯이 없어서 잠금화면 고정 카드(알림)로 대신했습니다.
  유료 Pro, iCloud 동기화, Apple Watch 지원은 사내 용도에 맞지 않아 넣지 않았고, 모든 기능을 제한 없이 씁니다.
- **코드**: 원작의 코드, 디자인 리소스, 이미지는 하나도 사용하지 않았습니다. 공개된 앱 소개를 참고해 처음부터 새로 작성했습니다.

> **비공식 오마주 앱입니다.** 이 프로젝트는 툭(Took) 및 그 개발자([Jahyeon Ko](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982) / (주)티엔티랩스)와
> 아무런 제휴·후원·승인 관계가 없습니다. "툭(Took)"의 이름, 콘셉트, 디자인에 대한 모든 권리는 원 개발자에게 있습니다.
> 좋은 아이디어를 보여준 원작에 감사드리며, iPhone을 쓰신다면 원작 툭을 꼭 써 보세요.

## 잠금화면 표시 방식

안드로이드 폰에는 iOS 같은 잠금화면 위젯이 없어서, **잠금화면에 공개(VISIBILITY_PUBLIC)되는 고정(ongoing) 알림**을 카드로 씁니다.

- 펼친 카드: 날짜, 진행률(2/5), D-day·문구, 할 일 최대 6줄, `＋ 추가`
- 접힌 카드: 다음 할 일 한 줄 + 체크 버튼
- 체크는 브로드캐스트라서 잠금을 풀지 않아도 동작합니다.
- **카드를 탭하면**(`＋ 추가` 포함) 잠금화면 위에 패널이 뜹니다. 오늘 할 일 전체를 보고 체크하고, 적고 엔터로 추가합니다. `앱 열기`만 잠금 해제를 요구합니다.
  - 카드 안 버튼에 화면을 여는 PendingIntent 를 걸면 시스템이 무조건 PIN 부터 요구합니다. 카드 전체 탭(contentIntent)은 대상 화면이 `showWhenLocked` 이면 잠금 위에 바로 열어 주므로 이쪽을 씁니다.
- 안드로이드 14+에서 사용자가 카드를 밀어 지우면 바로 다시 띄웁니다.
- 글자 크기: 설정 → 잠금화면 카드 → **카드·위젯 글자** (보통 16 / 크게 19 / 아주 크게 23sp, 기본 크게). 클수록 펼친 카드 줄 수가 6 → 5 → 4 로 줄어듭니다(시스템이 카드 높이를 자름).

### 화면 켜면 딱 화면 먼저 보기 (기본, 툭 방식)

설정 → 잠금화면 → **화면 켜면 딱 화면 먼저 보기** (기본 켜짐). 화면을 켤 때마다 잠금화면 위에 딱 화면이 먼저 뜹니다.

- 툭의 잠금화면처럼 **폰 배경화면 위에 시계와 유리 카드 하나**만 있습니다. 카드에는 동그라미 + 큰 글씨 줄만, 아래 `＋ 할 일 추가`를 누르면 그 자리가 입력칸이 됩니다. 앱 아이콘·이름 같은 군더더기 없음.
- **동그라미**를 눌러야만 체크됩니다(체크 표시가 잠깐 보였다가 사라짐). **글씨를 누르면 앱**이 열리고(밀어서 잠금이면 바로, PIN 이면 PIN 뒤에), **글씨를 길게 누르면** 그 자리에서 이름을 고칩니다(키보드 '완료'로 저장, 키보드를 내리면 취소).
- 아래 반투명 **바로가기(3×3, 최대 9개)**: 기본은 **계산기**(잠금을 풀고 항암 주입속도 계산기로)와 **알람**("몇 분 뒤?" 숫자만 입력, 이름은 `+ 이름 붙이기`를 눌렀을 때만). 설정 → **딱 화면 바로가기**에서 폰의 앱을 골라 넣고, 눌러서 버튼 이름을 바꾸고(비우면 앱 이름), ↑로 순서를 바꾸고, ✕로 뺍니다. 앱 바로가기를 누르면 잠금을 풀고 그 앱이 열립니다.
- 맞춰 둔 알람은 시계 아래에 남은 시간이 초 단위로 보이고 `✕`로 취소합니다.
- 알람은 정확한 알람(`setExactAndAllowWhileIdle`)으로 맞춰 상태바에 ⏰가 뜨지 않습니다. 울리면 화면이 켜지며 잠금 위에 알람 화면이 뜨고 `끄기`를 누를 때까지 울립니다(10분 뒤 저절로 멈춤). 재부팅해도 다시 맞춥니다. 깊은 절전 중에 알람이 몇 분 간격으로 연달아 있으면 뒤의 것이 조금 늦을 수 있습니다.
- 설정 → **알람**: 알람음 고르기, 크기(1~10, 울리는 동안만 폰 알람 음량을 그만큼으로 맞췄다가 되돌림), 방식(소리+진동 / 소리만 / 진동만), **무음·진동 모드여도 소리로 울리기**(끄면 그땐 진동만), 들어 보기(3초).
- 잠금은 풀리지 않습니다. **위로 밀거나** 뒤로 가기를 누르면 원래 잠금화면으로 돌아갑니다. 잠금화면 카드를 눌러 열어도 같은 화면(목록부터), 상단바 타일·위젯 `＋`로 열면 바로 입력칸이 열립니다.
- **'다른 앱 위에 표시'** 허용이 필요합니다(백그라운드에서 화면을 띄우는 데 필요). 안드로이드 11+ 는 앱 하나가 아니라 목록이 열려서, 목록에서 '딱'을 찾아 켭니다. 설정 안내(오늘 탭 '잠금화면 설정 N개 남음')가 확인하고 이 화면을 엽니다.
- 화면 켜짐 신호를 받으려고 상시 서비스로 돕니다. 딱 화면을 쓰면 잠금화면 카드·라이브 알림은 겹쳐서 띄우지 않고, 서비스용 조용한 알림('딱 화면 유지')만 둡니다. 안드로이드가 이 알림을 완전히 숨기게 두지 않아 상태바에 ✓가 남는데, 설정 → **상태바의 딱 아이콘 숨기기**로 그 알림 종류를 끄면 사라지고 딱 화면은 그대로 동작합니다(에뮬레이터 확인).
- 갤럭시 One UI 9·8.5(밀어서 잠금)에서 화면 켜기 → 자동 표시 → 잠긴 채 체크 → 추가 → 위로 밀어 닫기를 확인했습니다. 재부팅·업데이트 뒤 서비스가 저절로 다시 켜지는 것은 안드로이드 16 에뮬레이터에서 확인(부팅 뒤 약 1분 걸림).

알림 기반 방식과 다른 점: 안드로이드 알림은 앱 아이콘·이름 줄을 시스템이 강제로 붙이고, 라이브 알림(Live Updates)은 줄마다 체크하는 커스텀 화면을 받지 않습니다(커스텀 카드에 promoted 요청을 붙여도 거부됨, 실기기 확인). 그래서 툭처럼 보이려면 알림이 아니라 우리 화면을 잠금 위에 띄우는 이 방식이 필요합니다.

### 라이브 알림 모드 (딱 화면을 끈 경우, 안드로이드 16+)

딱 화면을 끄면 잠금화면 카드 방식이 되고, 안드로이드 16+ 에서는 설정 → 잠금화면 → **라이브 알림으로 늘 펼쳐 보기**(기본 켜짐)를 쓸 수 있습니다. 안드로이드 Live Updates(아이폰 Live Activity 에 해당)로 카드를 올립니다.

- 잠금화면 맨 위에 **누르지 않아도 오늘 할 일 전체가 펼쳐진 채로** 보이고, 화면을 껐다 켜도 접히지 않습니다.
- 대신 시스템 기본 모양만 쓸 수 있어서(커스텀 화면이면 시스템이 올려 주지 않음) 줄마다 체크는 안 되고, 아래 **완료 버튼(남은 할 일 위에서 3개까지, 시스템 한도)**으로 잠긴 채 체크합니다. 그 아래 할 일은 카드를 눌러 딱 화면에서 체크합니다. 제목은 시스템이 꼭 요구해서 날짜 없이 진행률(1/4)만 둡니다. 앱 아이콘·이름 줄과 글자 크기는 시스템이 정합니다.
- `POST_PROMOTED_NOTIFICATIONS` 권한(설치 시 자동 허용)과 알림의 promoted 요청으로 동작하고, targetSdk 35 그대로 됩니다.
- 사용자가 앱 알림 설정에서 딱의 라이브 알림을 끄면 일반 알림으로 내려갑니다. 설정의 '잠금화면에서 쓰려면' 6번이 이걸 감지해 켜는 화면을 바로 엽니다.
- **삼성은 라이브 알림 모드도 잠금화면 알림 스타일이 '카드'여야 보입니다.** 기본값 '아이콘'에서는 라이브로 올라가 있어도 잠금화면에 아무것도 안 나옵니다(One UI 8.5 실기기 확인). 삼성 앱 알림 설정에는 라이브 알림 토글이 따로 없습니다.
- **삼성 Now Bar(잠금화면 아래 알약)에는 못 들어갑니다.** One UI 8.5 정식 버전의 설정 → 잠금 화면 및 AOD → Now bar → 실시간 정보 목록은 삼성·구글이 고른 앱(지도, 삼성 헬스, 구글 스포츠 등)만 보여 주고, 딱은 라이브 알림으로 올라가 있어도 목록에 없습니다(실기기 확인). 그래서 삼성에서는 잠금화면 맨 위에 펼쳐진 알림 모양으로만 보입니다.

### 삼성 One UI 에서 꼭 할 설정

- **잠금화면 알림 스타일 '카드'**: 설정 → 알림 → 잠금화면 → 알림 스타일 → **카드**. 기본값 '아이콘'에서는 딱 카드가 안 보입니다.
  - 앱의 설정 도우미 3번이 현재 값을 읽어 '아이콘'(한 번도 안 바꾼 폰은 값이 비어 있고 이때도 아이콘)이면 알려 주고, `설정 열기` 한 번에 바로 이 화면을 엽니다.
  - 앱이 직접 바꾸는 건 안드로이드가 막습니다(시스템 설정 변경 권한을 줘도 거부됨).
  - PC 로 여러 대를 맞출 때: `adb shell settings put system lockscreen_minimizing_notification 0` (0 카드, 1 아이콘, 2 동그란 점). 바로 반영됩니다.
- **"소리 알림만 표시"는 끄기**: 켜져 있으면 소리 없는 딱 카드는 잠금화면에 안 나옵니다.
- **상단바 타일**: 오른쪽 위에서 내린 빠른 설정창 **맨 아래**에 이름 없이 ✓ 버튼으로 들어갑니다.

## 계산기 — 항암약물 주입속도

```
총 주입량(cc)   = Base fluid + mix된 항암 fluid (+ Priming, 기본 20cc)
주입속도(cc/hr) = 총 주입량 ÷ 투여시간(hr)        예) 100 + 50 + 20 = 170cc, 120분 → 85.0 cc/hr
```

- 숫자 칸 넷(Base · 항암 · Priming · 투여시간)을 넣으면 바로 계산하고, 결과·계산 과정·참고용 문구까지 한 화면에 보입니다.
- Priming 은 항암제가 아닌 **별도 수액으로 line 을 채운 용량**이라 환자에게 같이 들어가므로 기본으로 총량에 더합니다(기본 20cc). `포함 / 빼기` 로 뺄 수 있습니다.
- 키보드 `다음` 은 바로 아래 숫자 칸으로 갑니다. 분 ↔ 시간 단위를 바꾸면 시간 칸을 비웁니다 (120분이 120시간으로 바뀌는 실수 방지).
- 잘못 적은 값(숫자가 아님, 0 이하의 시간, `1,000` 처럼 쉼표)은 결과 대신 빨간 안내로 알려 줍니다.
- 기억하는 것은 **시간 단위뿐**이고 용량은 저장하지 않습니다. 공용 폰에서 다음 사람이 이전 환자 값을 그대로 쓰지 않도록 하기 위해서입니다.
- 계산 결과는 참고용입니다. 처방과 기관 지침을 반드시 확인하세요.

### 기기 설정 (MDM 배포 시 정책으로 지정 권장)

설정 탭의 **"잠금화면에서 쓰려면"** 점검 카드가 각 단계가 제대로 됐는지 자동으로 확인하고, 버튼 한 번으로 알림 허용 · 카드 다시 띄우기 · 상단바 타일 추가(안드로이드 13+) · 홈 위젯 추가를 할 수 있습니다.
처음 설정용으로 오늘 탭에도 한 줄(**"잠금화면 설정 N개 남음"**)로 접혀 뜨는데, 꼭 필요한 단계(알림 허용 · 카드 · 알림 스타일 · 라이브)만 세고 다 끝나면 저절로 사라집니다. `닫기`로 바로 숨길 수도 있습니다.
잠금화면 알림 표시 방식만은 폰 설정이라 직접 바꿔야 합니다:

1. 알림 권한 허용 (안드로이드 13+ 첫 실행 시 요청)
2. 잠금화면 알림 **내용 표시** 켜기
   - 삼성 One UI 7+: 설정 → 알림 → 잠금화면 → 알림 스타일 **카드**, "소리 알림만 표시"는 끄기 (위 표 참고)
   - 삼성 One UI 6 이하: 설정 → 잠금화면 → 알림 → 스타일 **상세히**
   - 픽셀: 설정 → 알림 → 잠금 화면의 알림 → **모든 알림 내용 표시**
3. (선택) 상단바 편집에서 `딱 추가` 타일 추가
