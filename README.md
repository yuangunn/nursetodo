# 딱 (ttaak)

> 적고, 딱 체크. 그게 전부.

iOS 앱 [툭(Took)](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982)을 오마주한 안드로이드용 초간단 투두리스트입니다.
**인트라넷(폐쇄망) 안드로이드 폰의 잠금화면**에서 오늘 할 일을 보고, 잠금을 풀지 않고 체크하는 것이 핵심입니다.

## About

**딱**은 iOS 투두 앱 **툭(Took)** 에 바치는 안드로이드 **오마주(homage) 앱**입니다.

툭은 "세상에서 제일 빠른 투두리스트"를 내세워, 다른 투두 앱들이 붙이는 군더더기를 덜어내고
*적고, 바로 체크하는 것*만 남긴 앱입니다. 잠금화면에서 오늘 할 일을 보고 바로 체크하는 경험이 특히 좋았는데,
안드로이드에는 같은 앱이 없었습니다. 그래서 그 철학과 사용 흐름을 안드로이드로 옮겨 보았습니다.

- **이름**: 툭 → 딱. 할 일을 *툭* 적고 *딱* 끝낸다는 의미로, 원작에 대한 존중을 담아 짝이 되는 이름을 붙였습니다.
- **목적**: 인터넷이 막힌 사내(인트라넷) 안드로이드 폰에서, 계정·서버·동기화 없이 잠금화면만으로 하루 할 일을 관리하기 위해 만들었습니다.
- **원작과 다른 점**: 안드로이드에는 iOS의 Live Activity나 잠금화면 위젯이 없어서 잠금화면 고정 카드(알림)로 대신했습니다.
  유료 Pro, iCloud 동기화, Apple Watch 지원은 사내 용도에 맞지 않아 넣지 않았고, 모든 기능을 제한 없이 씁니다.
- **코드**: 원작의 코드, 디자인 리소스, 이미지는 하나도 사용하지 않았습니다. 공개된 앱 소개를 참고해 처음부터 새로 작성했습니다.

> **비공식 오마주 앱입니다.** 이 프로젝트는 툭(Took) 및 그 개발자([Jahyeon Ko](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982) / (주)티엔티랩스)와
> 아무런 제휴·후원·승인 관계가 없습니다. "툭(Took)"의 이름, 콘셉트, 디자인에 대한 모든 권리는 원 개발자에게 있습니다.
> 좋은 아이디어를 보여준 원작에 감사드리며, iPhone을 쓰신다면 원작 툭을 꼭 써 보세요.

## 기능

| 툭 (iOS) | 딱 (Android) |
| --- | --- |
| 잠금화면 Live Activity 카드 | 잠금화면 고정 카드 (공개 + 고정 알림, 커스텀 레이아웃) — 줄을 탭하면 잠금 해제 없이 체크 |
| 잠금화면 바로가기 버튼 | 카드의 `＋ 추가` / 빠른 설정 타일 `딱 추가` → 잠금화면 위에 바로 뜨는 입력창 |
| 홈 화면 위젯 | 홈 화면 위젯 (탭하면 체크, `+`로 추가) |
| 오늘 할 일 / 완료 항목은 아래로 | 동일 |
| 드래그로 순서 변경, 새 항목 위치 설정 | 길게 눌러 끌기 / 설정 → 새 할 일 위치 |
| 일정(날짜 지정) / 캘린더 탭 | 할 일 탭 → 오늘·내일·날짜 선택, 캘린더 탭 (못 끝낸 일은 오늘로 넘어옴) |
| 루틴 요일 선택 | 할 일 탭 → 반복 요일 선택 |
| 잠금화면 D-day / 문구 | 설정 → 카드 문구, D-day |
| 디자인 탭 (테마 색, 글자 크기·굵기, 체크 위치) | 설정 → 디자인 |
| 데이터는 기기에만 | **INTERNET 권한 자체가 없음.** 앱 내부 저장소의 JSON 파일 하나에만 저장 |

그 밖에: 왼쪽으로 밀어 삭제, 다크 모드, 런처 아이콘 길게 눌러 `할 일 추가`, 부팅·자정·시간대 변경 시 카드 자동 갱신.
Pro 결제·iCloud 동기화·Apple Watch 는 인트라넷 용도에 맞지 않아 제외했습니다 (모든 기능 무료, 개수 제한 없음).

## 잠금화면 표시 방식

안드로이드 폰에는 iOS 같은 잠금화면 위젯이 없어서, **잠금화면에 공개(VISIBILITY_PUBLIC)되는 고정(ongoing) 알림**을 카드로 씁니다.

- 펼친 카드: 날짜, 진행률(2/5), D-day·문구, 할 일 최대 6줄, `＋ 추가`
- 접힌 카드: 다음 할 일 한 줄 + 체크 버튼
- 체크는 브로드캐스트라서 잠금을 풀지 않아도 동작하고, `＋ 추가`는 `showWhenLocked` 액티비티라 잠금화면 위에서 바로 입력합니다.
- 안드로이드 14+에서 사용자가 카드를 밀어 지우면 바로 다시 띄웁니다.

### 기기 설정 (MDM 배포 시 정책으로 지정 권장)

앱을 처음 열면 오늘 화면 위에 **"잠금화면에서 쓰려면"** 점검 카드가 뜹니다(설정 탭에도 있음).
각 단계가 제대로 됐는지 자동으로 확인하고, 버튼 한 번으로 알림 허용 · 카드 다시 띄우기 · 상단바 타일 추가(안드로이드 13+) · 홈 위젯 추가를 할 수 있습니다.
잠금화면 알림 표시 방식만은 폰 설정이라 직접 바꿔야 합니다:

1. 알림 권한 허용 (안드로이드 13+ 첫 실행 시 요청)
2. 잠금화면 알림 **내용 표시** 켜기
   - 삼성 One UI: 설정 → 잠금화면 → 알림 → 스타일 **상세히**, "조용한 알림 표시"는 상관없음
   - 픽셀: 설정 → 알림 → 잠금 화면의 알림 → **모든 알림 내용 표시**
3. (선택) 상단바 편집에서 `딱 추가` 타일 추가

## 빌드

요구사항: JDK 17+, Android SDK 35

```bash
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # 날짜·루틴 로직 + Robolectric 렌더링/실행 테스트
```

- minSdk 26 (Android 8.0), targetSdk 35
- release 는 별도 키스토어가 없으면 debug 키로 서명됩니다. 사내 정식 배포 시 `app/build.gradle.kts` 의 `signingConfig` 를 사내 키로 바꾸세요.
- GitHub Actions 가 PR/main 푸시마다 테스트·lint 후 `ttaak-apk` 아티팩트로 APK 를 올립니다.
- 폐쇄망 안에서 빌드하려면 사내 Maven 미러(google, mavenCentral 프록시)를 `settings.gradle.kts` 에 지정하세요.
