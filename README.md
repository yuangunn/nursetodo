# 널스투두 (NurseTodo)

> 적고, 바로 체크. 그게 전부.

**간호사를 위한 잠금화면 기반 할 일(To-Do) 앱**입니다. iOS 앱 [툭(Took)](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982)을 오마주했습니다.
**병동 업무폰(인트라넷·폐쇄망)의 잠금화면**에서 오늘 할 일을 보고, 잠금을 풀지 않고 체크하는 것이 핵심입니다.
3교대에 맞춰 잠금화면에서 교대를 받으면 Day·Evening·Night 할 일 목록으로 바뀌고, 근무 시각마다 조용히 알려 주며, 항암 주입속도 계산기와 '몇 분 뒤'·'몇 시에' 알람이 딸려 있습니다.

> v1.5.1 까지 이름은 **딱(ttaak)** 이었습니다. v1.6.0 에서 이름과 함께 앱 ID 가 `com.ttaak.app` → `com.yuangunn.nursetodo` 로 바뀌어,
> 딱 위에 덮어 설치되지 않습니다. 아래 [딱에서 넘어오기](#딱에서-넘어오기)를 보세요.

## About

**널스투두**는 iOS 투두 앱 **툭(Took)** 에 바치는 안드로이드 **오마주(homage) 앱**에서 출발했습니다.

툭은 "세상에서 제일 빠른 투두리스트"를 내세워, 다른 투두 앱들이 붙이는 군더더기를 덜어내고
*적고, 바로 체크하는 것*만 남긴 앱입니다. 잠금화면에서 오늘 할 일을 보고 바로 체크하는 경험이 특히 좋았는데,
안드로이드에는 같은 앱이 없었습니다. 그래서 그 철학과 사용 흐름을 안드로이드로 옮겨 보았습니다.

- **이름**: 간호사(Nurse) + 할 일(To-do). 처음에는 툭과 짝을 이루는 '딱'이었는데, 병동에서 쓰는 앱이라는 게 바로 보이도록 v1.6.0 에서 바꿨습니다.
- **색**: 시그니처 블루. 아이콘은 짙은 남색(`#003876`), 체크·버튼은 어두운 잠금화면에서도 잘 보이도록 밝은 파랑(`#0054D1`)을 씁니다. 설정 › 테마·강조색에서 다른 색으로 바꿀 수 있습니다.
- **목적**: 인터넷이 막힌 사내(인트라넷) 안드로이드 폰에서, 계정·서버·동기화 없이 잠금화면만으로 하루 할 일을 관리하기 위해 만들었습니다.
- **원작과 다른 점**: 안드로이드에는 iOS의 Live Activity나 잠금화면 위젯이 없어서 잠금화면 고정 카드(알림)로 대신했습니다.
  유료 Pro, iCloud 동기화, Apple Watch 지원은 사내 용도에 맞지 않아 넣지 않았고, 모든 기능을 제한 없이 씁니다.
- **코드**: 원작의 코드, 디자인 리소스, 이미지는 하나도 사용하지 않았습니다. 공개된 앱 소개를 참고해 처음부터 새로 작성했습니다.

> **비공식 오마주 앱입니다.** 이 프로젝트는 툭(Took) 및 그 개발자([Jahyeon Ko](https://apps.apple.com/kr/app/%ED%88%AD/id6776935982) / (주)티엔티랩스)와
> 아무런 제휴·후원·승인 관계가 없습니다. "툭(Took)"의 이름, 콘셉트, 디자인에 대한 모든 권리는 원 개발자에게 있습니다.
> 좋은 아이디어를 보여준 원작에 감사드리며, iPhone을 쓰신다면 원작 툭을 꼭 써 보세요.

## 잠금화면 표시 방식

안드로이드 폰에는 iOS 같은 잠금화면 위젯이 없어서, **잠금화면에 공개(VISIBILITY_PUBLIC)되는 고정(ongoing) 알림**을 카드로 씁니다.

- 펼친 카드: 날짜, 진행률(2/5), 할 일 최대 6줄, `＋ 추가`
- 접힌 카드: 다음 할 일 한 줄 + 체크 버튼
- 체크는 브로드캐스트라서 잠금을 풀지 않아도 동작합니다.
- **카드를 탭하면**(`＋ 추가` 포함) 잠금화면 위에 패널이 뜹니다. 오늘 할 일 전체를 보고 체크하고, 적고 엔터로 추가합니다. `앱 열기`만 잠금 해제를 요구합니다.
  - 카드 안 버튼에 화면을 여는 PendingIntent 를 걸면 시스템이 무조건 PIN 부터 요구합니다. 카드 전체 탭(contentIntent)은 대상 화면이 `showWhenLocked` 이면 잠금 위에 바로 열어 주므로 이쪽을 씁니다.
- 안드로이드 14+에서 사용자가 카드를 밀어 지우면 바로 다시 띄웁니다.
- 글자 크기는 할 일 화면·위젯 모두 고정(15sp)이고, 크게 보려면 휴대폰의 글꼴 크기를 키웁니다.

### 화면 켜면 할 일 화면 먼저 보기 (기본, 툭 방식)

설정 › 잠금화면 › **화면 켜면 할 일 먼저** (기본 켜짐). 화면을 켤 때마다 잠금화면 위에 할 일 화면이 먼저 뜹니다.

전화가 와서 화면이 켜졌거나 통화 중이면 할 일 화면을 띄우지 않아 수신·통화 화면을 가리지 않습니다. 일반 전화는 기본 전화 앱(삼성 전화·에이닷·익시오)과 상관없이 알아채고, 내선 앱 같은 인터넷 전화는 **다른 앱 알림 보기**(알림 접근)를 켜 두어야 알아챕니다. 할 일 화면을 보고 있을 때 오는 전화는 다른 앱을 쓸 때처럼 위쪽 알림 띠(받기·거절)로 뜹니다.

- 폰 배경화면 위 어두운 그라데이션에 위에서 아래로 **시계 · 키워드 알림 카드 · 알람 줄 · 페이지 줄(할 일 · 근무 · 포켓북, 알림, 설정) · 카드 · 할 일 추가 · 바로가기 · 잠금 해제 안내**를 쌓고, 카드만 남은 높이를 차지합니다. 글자는 세 페이지 모두 15/20, 동그라미 20(누르는 칸 40). 배경화면은 앱이 읽을 수 없어 흐림 없이 검정 72%로 덮습니다.
- `할 일 추가`를 누르면 그 자리가 입력칸(강조 테두리)이 되고, 추가나 키보드 완료로 맨 위에 넣고 닫습니다. 할 일 체크·체크 지우기·알람 끄기·할 일 추가·키워드 카드는 아래 **되돌리기 토스트**(4초, 교대 받기는 10초)로 되돌립니다.
- **할 일 추가 버튼은 한 군데만** (설정 › 잠금화면 › 할 일 추가 버튼): 카드 아래, 또는 카드 안 오른쪽 아래 둥근 버튼(오른쪽·아래 간격이 같고, 알림 세로 줄이 있으면 그 바로 아래). 바로가기에 `할 일 추가`를 넣으면 위쪽 버튼은 숨겨집니다.
- **동그라미**를 눌러야만 체크됩니다(할 일은 취소선으로 남았다가 토스트가 사라지면 카드 바닥의 **완료 줄**(완료 N · 마지막 시각)로 들어가고, 완료 줄을 누르면 카드 자리에 끝낸 순서대로 끝낸 시각과 함께 보입니다. 거기서 동그라미를 누르면 다시 할 일로, 아래 **모두 지우기**는 끝낸 일을 한 번에 지웁니다 — 루틴과 근무 할 일은 남기고, 토스트로 되돌릴 수 있음). 할 일 줄 오른쪽에는 만든 시각이 작게 보입니다(오늘은 시:분, 어제, 그 전은 월/일). **글씨를 누르거나 길게 누르면** 그 줄 아래에 메뉴가 뜹니다: `타이머 맞추기`(그 할 일 이름이 채워진 알람 칸), `○ 근무로 옮기기`(할 일 페이지에서, 받은 근무가 있을 때 — 할 일에서 빼서 그 근무 목록 맨 아래로, 루틴은 빼고), `이름 고치기`(그 자리에서, 키보드 '완료'로 저장), `지우기`, `앱에서 자세히 고치기`(날짜·반복, 밀어서 잠금이면 바로, PIN 이면 PIN 뒤에). 옮기기·지우기는 토스트로 되돌립니다. 근무 페이지 줄에도 같은 메뉴(옮기기 없음).
- 시계는 날짜와 한 줄, 늘 24시간제(07:39). 페이지 줄 오른쪽 톱니는 잠금을 풀고 앱 설정을 엽니다.
- **다른 앱 알림** — **알림판에만** 있습니다(아래 '설치: 기본판과 알림판'). 설정 › 다른 앱 알림 › '알림 접근' 허용: 할 일 페이지는 카드 안 오른쪽 아래 옅은 바탕의 세로 줄(맨 위 종, 앱마다 아이콘, 최근 3개 앱, 같은 앱 2개 이상이면 개수), 근무·포켓북 페이지는 페이지 줄의 알림 버튼(종 · 최근 앱 아이콘 2개 · 전체 개수). 누르면 카드 자리에 알림 목록이 열리고, 줄을 누르면 잠금을 풀고 그 알림의 화면이 열립니다. 확인한 알림은 줄 오른쪽 **✕** 나 아래 **모두 지우기**로 잠금을 풀지 않고 지웁니다(알림 창에서도 지워지고 되돌릴 수 없음). 시스템 잠금화면에 안 뜨는 알림(계속 떠 있는 알림, 조용한 알림, 잠금화면에서 숨긴 알림)은 빼고, 앱·알림 종류별로 잠금화면 내용을 숨긴 알림은 앱 이름·시각만 보입니다. 읽은 알림은 폰 밖으로 나가지 않습니다(인터넷 권한 없음).
  - **알림 볼 앱**에서 메시지·팀즈처럼 몇 개 앱만 고를 수 있습니다. 아무것도 안 고르면 모든 앱.
  - 기본판과 알림판을 바꿔 깔면 알림 접근이 끊깁니다. 설정 줄이 '다시 켜기'로 보이면 눌러서 다시 켜 주세요.
  - APK 파일로 설치하면 안드로이드 13+ 가 '알림 접근'을 막아 둡니다(스위치가 회색). 앱 정보 → 오른쪽 위 ⋮ → **제한된 설정 허용** 뒤 다시 켜면 됩니다. 앱 설정의 '허용이 막혀 있으면 → 앱 정보'가 그 화면을 엽니다.
- 아래 반투명 **바로가기** — 모양은 세 가지(설정 › 바로가기 › 모양): **한 줄 3개**(9개)·**한 줄 2개**(6개)는 높이 44 알약에 아이콘과 이름, **아이콘만**은 44 원을 가운데에 한 줄 5개씩(8개). 칸이 적은 모양으로 바꾸면 뒤쪽 바로가기는 저장만 되고 안 보입니다. 기본은 **항암계산기**(잠금을 풀고 항암 주입속도 계산기로), **알람**("몇 분 뒤?" 숫자만 입력, 이름은 `+ 이름 붙이기`를 눌렀을 때만), **캘린더**(잠금을 풀고 앱의 캘린더 탭으로). 설정 → **할 일 화면 바로가기**에서 폰의 앱이나 `할 일 추가`를 골라 넣고, 눌러서 버튼 이름을 바꾸고(비우면 앱 이름), 길게 눌러 끌어 순서를 바꾸고, ✕로 뺍니다. 앱 바로가기를 누르면 잠금을 풀고 그 앱이 열립니다. 할 일 화면에서 **바로가기를 길게 누르면** 카드 자리에 편집 화면이 열려 모양을 바꾸고, 길게 눌러 끌어 순서를 바꾸고, ✕로 빼고, 기본 버튼이나 앱을 넣을 수 있습니다(아래 바로가기에 바로 보임).
- 맞춰 둔 알람은 시계 아래 **알람 줄**에 가장 빨리 울릴 것의 남은 시간(28분 · 1시간 12분 · 1분 안쪽은 초)과 이름이 보이고 `✕`로 끕니다. 둘 이상이면 `+N` 칩을 눌러 카드 자리에 울릴 시각순 알람 목록을 열고 하나씩 끕니다.
- 알람 버튼에서 **몇 분 뒤**(칩 5·10·15·30·60분 또는 숫자, 30분으로 열림) 또는 **몇 시에**(숫자만: `1430` → 14:30, 지난 시각이면 내일)를 고릅니다. 오른쪽에 울릴 시각·남은 시간을 미리 보여 줍니다.
- 알람은 시계 앱 방식(`setAlarmClock`)으로 맞춰 깊은 절전 중에도 제시간에 울리고, 상태바에 ⏰가 뜹니다. 울리면 화면이 켜지며 잠금 위에 알람 화면(이름 크게, `5분 뒤 다시 울림` · `끄기`)이 뜨고 끌 때까지 울립니다(10분 뒤 저절로 멈춤). 재부팅해도 다시 맞춥니다.
- 안드로이드 14+ 는 **'알람 및 리마인더'**를 허용해야 알람이 제시간에 울립니다. 새로 깔면 꺼져 있어 오늘 탭 안내와 알람 입력 칸(`'알람 및 리마인더'가 꺼져 있어 늦게 울릴 수 있어요`)에서 허용 화면을 엽니다. 허용하기 전에 맞춘 알람은 늦게 울릴 수 있고, 허용하면 제시간으로 다시 맞춥니다.
- 설정 › **알람**: 알람음 고르기, 크기(1~10, 기본 3, 울리는 동안만 폰 알람 음량을 그만큼으로 맞췄다가 되돌림), 방식(소리+진동 / 소리만 / 진동만), **무음·진동 모드여도 소리로 울리기**(끄면 그땐 진동만), 들어 보기(3초).
- 체크·추가하는 동안 잠금은 풀리지 않습니다. **위로 밀면 잠금이 풀립니다**(맨 아래 손잡이나 화면 아무 데서나, 미는 동안 화면이 따라 올라감. 할 일 화면에서는 아래 내비게이션 바를 숨겨 홈 제스처를 잘못 건드리지 않게 하고, 가장자리에서 밀면 잠깐 나타납니다. 처음 한 번 시스템의 '전체 화면' 안내가 뜹니다): 밀어서 잠금이면 바로 홈, PIN 이면 PIN 화면이 뜹니다(시스템 잠금화면을 한 번 더 넘기지 않음). 얼굴·지문으로 이미 풀었으면 한 번 밀어 닫습니다. 뒤로 가기는 원래 잠금화면으로 돌아갑니다. 화면 잠금이 **'없음'**인 폰은 화면을 켤 때 잠금화면 대신 할 일 화면이 뜹니다. 잠금화면 카드를 눌러 열어도 같은 화면(목록부터), 상단바 타일·위젯 `＋`로 열면 바로 입력칸이 열립니다.
- **'다른 앱 위에 표시'** 허용이 필요합니다(백그라운드에서 화면을 띄우는 데 필요). 안드로이드 11+ 는 앱 하나가 아니라 목록이 열려서, 목록에서 '널스투두'을 찾아 켭니다. 설정 안내(오늘 탭 '잠금화면 설정 N개 남음')가 확인하고 이 화면을 엽니다.
- 화면 켜짐 신호를 받으려고 상시 서비스로 돕니다. 할 일 화면을 쓰면 잠금화면 카드·라이브 알림은 겹쳐서 띄우지 않고, 서비스용 조용한 알림('할 일 화면 유지')만 둡니다. 안드로이드가 이 알림을 완전히 숨기게 두지 않아 상태바에 ✓가 남는데, 설정 › 잠금화면 › **상태바 아이콘 숨기기**로 그 알림 종류를 끄면 사라지고 할 일 화면은 그대로 동작합니다(에뮬레이터 확인).
- 갤럭시 One UI 9·8.5(밀어서 잠금)에서 화면 켜기 → 자동 표시 → 잠긴 채 체크 → 추가 → 위로 밀어 닫기를 확인했습니다. 재부팅·업데이트 뒤 서비스가 저절로 다시 켜지는 것은 안드로이드 16 에뮬레이터에서 확인(부팅 뒤 약 1분 걸림).

### 교대 프리셋 (3교대 병동 폰)

설정 › **교대 프리셋** › `교대 프리셋 사용`. 기본 프리셋은 **Day 07:00 · Evening 15:00 · Night 23:00**(할 일은 비어 있음). 교대는 **잠금화면에서 받아야 바뀝니다.**

- 프리셋을 누르면 전체 화면에서 이름·**근무 시작 시각**과 할 일 **두 칸**을 고칩니다. **시간별 할 일**은 앞에 `08:00`처럼 시각을 써서 그 시각에 알리고 지나면 미체크로 보이는 일(라운딩·혈당·투약), **이번 근무 할 일**은 시간과 상관없이 근무마다 하는 일(차팅·물품 카운트·처치 물품 수가·익일 식사 넣기)입니다. 한 줄에 하나, **두 칸 들여 쓴 줄은 위 줄의 하위 항목**. 다른 칸에 쓴 줄은 저장하면 제 칸으로 가고 칸 아래에 미리 알려 줍니다. `반복해서 넣기`는 이름·시작·끝 시각·간격(30분~6시간)으로 `08:00 라운딩`, `10:00 라운딩` … 처럼 회차마다 한 줄씩 넣습니다(끝이 시작보다 이르면 자정을 넘김). `복제`, `삭제`(한 번 더 눌러 확인), `지금 불러오기`(시각과 상관없이 지금 목록을 그 프리셋으로, 알림은 그대로), `프리셋 추가`. 지금 목록의 프리셋에 '지금' 표시.
- **다른 사람과 주고받기**(인터넷 없음): `다른 사람과 공유하기`에서 보낼 프리셋을 골라 **팀즈에 올리기**(팀즈가 깔려 있으면, 팀즈 화면에서 채팅이나 채널을 고름) 또는 다른 앱(카톡·문자 등)으로 보냅니다. 글로 나가서 팀즈 채널·단톡방·카페 게시판에 올려도 읽힙니다(`▶ Day 07:00`, 하위 항목 `ㄴ`, 알림 끈 줄 `(알림 끔)`). 받은 사람은 글을 길게 눌러 복사한 뒤 `붙여넣어 가져오기`, 또는 공유하기로 `널스투두`를 고릅니다. 가져올 프리셋을 고르면 같은 이름은 바꾸고 없는 이름은 새로 넣습니다(지금 받은 근무의 할 일은 그대로). 환자·병원 이름이 들어가지 않았는지 보내기 전에 확인하세요.
- **교대 받기**: 근무 페이지 맨 위 `Night 근무 교대 받았습니다`(다음 근무 시작 1시간 전부터). 누르면 그 근무 프리셋으로 바뀌고 이 폰에서 근무 루틴 알림·키워드 알림이 켜집니다.
  - 앞 근무에 못 끝낸 항목이 있으면 카드 자리에 보여 주고 `Night로 가져오기` · `취소` · `지우고 받기` 중 고릅니다. 가져온 항목은 'Evening에서 넘어옴' 아래 맨 위에 미체크로 남습니다(하위 체크 그대로).
  - 받으면 **포켓북 체크를 지우고 꺼 둔 루틴 알림을 다시 켭니다.** 토스트 둘째 줄에 한 것만 적고, 10초 안에 `되돌리기`로 모두 받기 전으로 돌립니다.
  - 시작 시각이 지나도 안 받으면 앞 근무 목록·체크를 그대로 두고 'Night 23:00 시작, 20분 지남'을 진하게 보입니다. 다음 근무도 끝나도록 안 받으면 지금 시각에 맞는 근무를 시작할지 묻습니다(`Day 근무 시작`).
- **직접 추가한 할 일은 그대로**, 끝낸 프리셋 할 일은 '끝낸 할 일' 기록에 남습니다. 프리셋을 고쳐 저장하면 지금 목록을 다시 불러오되 이미 끝낸 것·가져온 것은 그대로. 끄면 못 끝낸 프리셋 할 일을 치웁니다.
- 할 일 화면은 **할 일**(직접 적은 일)·**근무**(프리셋에서 온 일)·**포켓북** 페이지를 좌우로 넘겨 봅니다(위 이름을 눌러도 됨). 처음엔 근무 페이지. 설정 › 잠금화면 › 보일 페이지에서 하나 이상 고릅니다.
- 근무 페이지: 맨 위 근무 상태는 고정이고 그 아래 **두 칸이 따로 스크롤**됩니다. 위 **지금 할 일**은 시간별 할 일 중 미체크 · 시각이 된 것 · 다음 것만 보이고, 끝낸 것과 나중 것은 맨 아래 `이후 3개 · 20:00부터 · 끝낸 1` 한 줄로 접힙니다(그 줄이나 '지금 할 일' 줄을 누르면 시간별 전체). 방금 체크한 줄은 4초 동안 제자리에 남았다가 접힙니다. 아래 **이번 근무 할 일**은 끝낸 것도 제자리에 체크 시각과 함께 남고, 끝낸 수/전체와 진행 막대가 보입니다. 앞 근무에서 넘어온 것은 시각 있는 줄은 위 칸, 없는 줄은 아래 칸 맨 위. 두 칸은 내용만큼 차지하고 둘 다 넘치면 반씩 나눕니다. 시간별만 있는 프리셋은 접지 않고 전체 시간표를 보입니다. 줄은 동그라미 · 시각 칸(이번 근무 할 일은 없음) · 내용. **시각이 지나고 30분 넘게 안 한 항목은 '미체크'(빨강)**, 그 밖의 첫 항목은 '다음'(진하게), 끝낸 항목은 체크 시각과 함께 남습니다. 하위 항목이 있는 줄은 오른쪽 `1/3` 칩으로 펼치고, 위 동그라미는 모두 체크·모두 풀기. 30분은 임시값이라 기관 투약 지침으로 확인하세요.
- **근무 루틴 알림**: 할 일 앞에 `07:00 정규 라운딩(환자상태 확인, V/S check)`처럼 시각을 쓰면 그 시각에 알립니다(프리셋 고치기의 `예시 불러오기 (Day)` — 그 근무 이름이나 시작 시각에 맞는 Day · Evening · Night 예시의 시간별 할 일과 이번 근무 할 일을 두 칸에 넣음).
  - 병동 공용폰은 근무 인원보다 많을 수 있어서, 교대를 받은 폰만 울립니다. 근무 중 상태 줄의 `루틴 알림 끄기`로 끄고 `켜기`로 다시 켭니다(다음에 교대를 받으면 다시 켜짐).
  - 소리 없이 짧은 진동과 팝업(`완료` · `10분 뒤`)만 뜨고, 화면이 꺼져 있으면 잠깐 켜서 근무 페이지를 보여 줍니다. 이미 끝낸 항목은 알리지 않습니다. 하위 줄은 알리지 않습니다.
  - 직접 맞춘 알람(끌 때까지 울림)과 울리는 방식이 다릅니다. 설정에서 `근무 루틴 알림`을 끄면 전체가, 프리셋 고치기의 줄별 스위치로 항목마다 꺼집니다.
- **키워드 알림**(알림판): 설정 › 키워드 알림에 `배정되었습니다`처럼 낱말을 하나씩 추가하면(`키워드 추가`, ✕로 빼기), 고른 앱(처음엔 삼성 메시지·구글 메시지·팀즈)의 새 알림 보낸 사람·내용에 그 낱말이 있을 때 알립니다. 띄어쓰기·대소문자는 가리지 않습니다.
  - **교대 프리셋을 쓰면** 근무 루틴 알림처럼 교대를 받은 폰에서만 그 근무 동안, **안 쓰면** 켜 둔 동안 늘 울립니다(설정 첫 화면 키워드 알림 줄에 `늘` / `근무 받은 동안`). `키워드 알림 받기`로 끄고 켭니다.
  - 진동을 몇 번 되풀이하고(약 12초, 설정 › 키워드 알림 › 소리·진동에서 `소리와 진동`을 고르면 휴대폰 알림 설정에서 소리를 고름), 꺼진 화면은 잠깐 켭니다. 팝업과 할 일 화면 시계 아래 **붉은 카드**에 `확인` · `열기`(잠금을 풀고 그 문자·팀즈를 엶) · `할 일로 추가`(내용의 첫 문장 40자를 맨 위에). 시스템 팝업은 몇 초면 접히지만 카드는 확인할 때까지 남고, 2건이면 새 것을 펼치고 이전 것은 한 줄로 접습니다.
  - 대화방 알림은 마지막 메시지만 봐서, 키워드 문자 뒤에 다른 문자가 와도 다시 울리지 않습니다. 원래 알림을 읽거나 지우면 팝업도 사라집니다.
  - 폰에 알림이 떠야 찾을 수 있습니다. 팀즈가 PC 사용 중엔 폰 알림을 안 보내게 되어 있거나 메시지 미리보기를 껐으면 내용이 없어 못 찾습니다.
- 다른 앱 알림(알림판)은 오른쪽 세로 줄에 **알림이 온 앱 아이콘**(최근 것부터, 2개 이상이면 숫자)으로 보입니다. 아이콘을 누르면 그 앱 알림이 위에 펼쳐지고(제목·시각·내용), 알림을 누르면 잠금을 풀고 열립니다. 바깥이나 뒤로 가기로 닫습니다.

알림 기반 방식과 다른 점: 안드로이드 알림은 앱 아이콘·이름 줄을 시스템이 강제로 붙이고, 라이브 알림(Live Updates)은 줄마다 체크하는 커스텀 화면을 받지 않습니다(커스텀 카드에 promoted 요청을 붙여도 거부됨, 실기기 확인). 그래서 툭처럼 보이려면 알림이 아니라 우리 화면을 잠금 위에 띄우는 이 방식이 필요합니다.

### 포켓북 (진단명·수술명·업무별로 사정할 때 볼 것)

아래 탭 **포켓북**에 적어 두면 할 일 화면의 **포켓북** 페이지에서 잠금을 풀지 않고 펼쳐 봅니다. 기관마다 지침이 달라 직접 적습니다.

- 만들기: `붙여넣기`(전체 화면, 글·미리 보기, 아래 `# 이름` · `## 묶음` · `- 체크` · `들여쓰기` 키)에 아래 형식의 글을 붙여 넣습니다(여러 개를 한 번에 넣어도 됨). 엑셀 표(`포켓북 | 묶음 | 항목 | 하위 항목`, 빈칸은 윗줄 값을 이어받음)를 복사해 넣어도 됩니다. `예시 포켓북 3개 넣기`(비었을 때)·`예시 넣기`는 정규 라운딩·간경화·LAR, `양식 저장 (글)`·`양식 저장 (표)`는 예시 파일을 폰에 저장합니다([글 예시](app/src/main/res/raw/pocketbook_example.txt), [표 양식](app/src/main/res/raw/pocketbook_table.tsv)).
  ```
  # LAR (저위전방절제술, 직장암)
  예시입니다. 기관 지침에 맞게 고쳐 쓰세요.
  ## POD#1
  - 걸터앉기 → 보행 시작
  - 출혈 징후
    - 배액관 혈성 다량
  ## 의료진에게 바로 알릴 때
  38도 이상 발열, 빈맥, 혈압 저하
  ```
  `#` 포켓북 하나 · `##` 묶음(접고 펴기, 체크 없음) · `-` 체크 항목(두 칸 들여 쓰면 하위 항목) · 그냥 줄은 설명.
- 고치기·지우기: 포켓북 탭에서 누르면 위 글 그대로 고칩니다(고치면 그 포켓북의 체크는 비움). 왼쪽 손잡이를 끌면 잠금화면 포켓북 페이지 순서가 바뀝니다.
- 할 일 화면: 이름을 누르면 펼치고, 묶음도 눌러 펼칩니다. 체크 항목은 동그라미, 설명은 흐린 글씨, 이름·묶음 옆에 `끝낸 수/전체`. 읽을 거리가 많아 작은 글씨로 한 화면에 많이 보이고, 카드 안에서 밀면 스크롤합니다(잠금은 안 풀림).
- 체크는 **같은 이름의 근무 루틴 알림**(예: `09:00 정규 라운딩(...)` → 포켓북 `정규 라운딩`)이 울릴 때, **교대를 받을 때**, 펼친 포켓북 맨 아래 `체크 지우기`(되돌리기 가능)로 새로 시작합니다.
- 할 일 화면 페이지는 설정 › 잠금화면 › `보일 페이지`에서 `할 일`·`근무`·`포켓북` 중 하나 이상 고릅니다. `근무`는 교대 프리셋을 켜야 보이고, 꺼져 있으면 고르는 칸이 흐리게 보입니다.
- 기관 단위로 포켓북을 서버에서 받고 업데이트하는 기능은 다음 마일스톤입니다([#15](https://github.com/yuangunn/nursetodo/issues/15)).

### 라이브 알림 모드 (할 일 화면을 끈 경우, 안드로이드 16+)

할 일 화면을 끄면 잠금화면 카드 방식이 되고, 안드로이드 16+ 에서는 설정 › 잠금화면 › **라이브 알림으로 늘 펼쳐 보기**(기본 켜짐)를 쓸 수 있습니다. 안드로이드 Live Updates(아이폰 Live Activity 에 해당)로 카드를 올립니다.

- 잠금화면 맨 위에 **누르지 않아도 오늘 할 일 전체가 펼쳐진 채로** 보이고, 화면을 껐다 켜도 접히지 않습니다.
- 대신 시스템 기본 모양만 쓸 수 있어서(커스텀 화면이면 시스템이 올려 주지 않음) 줄마다 체크는 안 되고, 아래 **완료 버튼(남은 할 일 위에서 3개까지, 시스템 한도)**으로 잠긴 채 체크합니다. 그 아래 할 일은 카드를 눌러 할 일 화면에서 체크합니다. 제목은 시스템이 꼭 요구해서 날짜 없이 진행률(1/4)만 둡니다. 앱 아이콘·이름 줄과 글자 크기는 시스템이 정합니다.
- `POST_PROMOTED_NOTIFICATIONS` 권한(설치 시 자동 허용)과 알림의 promoted 요청으로 동작하고, targetSdk 35 그대로 됩니다.
- 사용자가 앱 알림 설정에서 널스투두의 라이브 알림을 끄면 일반 알림으로 내려갑니다. 설정의 '잠금화면에서 쓰려면' 6번이 이걸 감지해 켜는 화면을 바로 엽니다.
- **삼성은 라이브 알림 모드도 잠금화면 알림 스타일이 '카드'여야 보입니다.** 기본값 '아이콘'에서는 라이브로 올라가 있어도 잠금화면에 아무것도 안 나옵니다(One UI 8.5 실기기 확인). 삼성 앱 알림 설정에는 라이브 알림 토글이 따로 없습니다.
- **삼성 Now Bar(잠금화면 아래 알약)에는 못 들어갑니다.** One UI 8.5 정식 버전의 설정 → 잠금 화면 및 AOD → Now bar → 실시간 정보 목록은 삼성·구글이 고른 앱(지도, 삼성 헬스, 구글 스포츠 등)만 보여 주고, 널스투두는 라이브 알림으로 올라가 있어도 목록에 없습니다(실기기 확인). 그래서 삼성에서는 잠금화면 맨 위에 펼쳐진 알림 모양으로만 보입니다.

## 계산기

계산기 탭 맨 위에서 `항암 주입속도` · `사용기한`을 고릅니다. 둘을 오가도 각자 적은 값은 남고, `모두 지우기`는 보이는 쪽만 지웁니다.

### 항암약물 주입속도

```
총 주입량(cc)   = Base fluid + mix된 항암 fluid (+ Priming, 기본 20cc)
주입속도(cc/hr) = 총 주입량 ÷ 투여시간(hr)        예) 100 + 250 + 20 = 370cc, 1시간 30분 → 246.7 cc/hr
```

- 숫자 칸(Base · 항암 · Priming · 투여시간 시간·분)을 넣으면 바로 계산하고, 결과·계산 과정·참고용 문구까지 한 화면에 보입니다. 칸은 모두 같은 폭이고 숫자 오른쪽 끝을 한 세로줄에 맞춥니다.
- Priming 은 항암제가 아닌 **별도 수액으로 line 을 채운 용량**이라 환자에게 같이 들어가므로 기본으로 총량에 더합니다(기본 20cc). 칸 안의 `포함 / 제외` 로 뺄 수 있습니다.
- 투여시간은 **시간·분 두 칸**이라 1시간 30분을 그대로 넣습니다(단위를 고르는 칸이 없어 120분이 120시간이 되는 실수가 없음). 한 칸만 적어도 됩니다.
- 결과 아래에 **지금 시작하면 끝나는 시각**과 `알람 맞추기`(그 시각에 '항암 끝' 알람)가 있습니다.
- 결과가 설정 › 항암계산기 › **주입속도 상한**(기본 1000 cc/hr, 기관·펌프 기준으로 정하세요)을 넘으면 숫자를 주황으로 바꾸고 '시간과 분 칸을 확인하세요'를 띄우며 알람 맞추기는 숨깁니다. 계산을 막지는 않고 값을 고치면 바로 돌아옵니다. 너무 작게 나온 값(분을 시간 칸에 넣은 경우)은 잡지 못합니다.
- 잘못 적은 값(숫자가 아님, 0 이하의 시간, `1,000` 처럼 쉼표)은 결과 대신 빨간 안내로 알려 줍니다.
- 용량은 저장하지 않습니다. 공용 폰에서 다음 사람이 이전 환자 값을 그대로 쓰지 않도록 하기 위해서입니다.
- 계산 결과는 참고용입니다. 처방과 기관 지침을 반드시 확인하세요.

### 사용기한 (개봉·부착·조제 후 ○시간 / ○일 / ○주 / ○개월 이내)

인슐린 펜, 패치 부착, 알코올젤·멸균 소독솜 개봉처럼 물품마다 정해진 기간이 달라서, **기간을 넣으면 바로 계산**하는 계산기입니다.

- 맨 위 `기간`(숫자 + 시간·일·주·개월)에 바로 커서가 있습니다. 시작한 날은 기본이 오늘이고 바꿀 수 있습니다(시간 단위는 시각도). 결과는 **○월 ○일 (요일)까지**와 남은 날(지나면 빨강).
- 자주 쓰는 기한은 위 칩. `+ 저장`으로 지금 기간을 이름과 함께 넣고(예: 산쿠소 패치 · 7일), 칩을 길게 누르면 뺍니다. 처음 칩(24시간 · 7일 · 28일 · 1개월 · 3개월 · 6개월)도 뺄 수 있습니다.
- 결과 아래 **라벨에 적을 때** 한 줄(`11/13 시작 · 11/20까지`)과 `할 일로 추가`(기한 날의 할 일로 넣어 그날 잠금화면·캘린더에 보임).
- 접힌 **옵션**: `제조사 유효기간`(넣으면 둘 중 빠른 날), `시작한 날을 1일째로 세기`(끄면 다음 날이 1일째라 1일에 열고 7일이면 8일까지, 켜면 7일까지 — 기관 지침대로 한 번 고르면 저장). 켜 둔 옵션은 접힌 줄에 보입니다. 개월은 달력 달로 더합니다(1월 31일 + 1개월 = 2월 말일).
- 적은 값은 저장하지 않습니다. 기한은 참고용입니다. 제조사 설명서와 기관 지침을 반드시 확인하세요.

## 설치: 기본판과 알림판

릴리스마다 APK 가 두 개 있습니다. 같은 앱이라 서로 덮어 설치되고 할 일은 그대로 남습니다.

| | 기본판 `nursetodo-vX.apk` | 알림판 `nursetodo-vX-noti.apk` |
|---|---|---|
| 다른 앱 알림 보기 | 없음 | 있음 |
| 파일 앱·브라우저로 설치 | 됨 | **안 됨** — 구글 Play 프로텍트가 '기기 보호를 위해 앱 차단됨'으로 막음(우회 버튼 없음) |
| 컴퓨터로 설치(adb) | 됨 | 됨 |

Play 프로텍트의 '강화된 사기 방지'는 알림 접근·문자 읽기·접근성을 쓰는 앱을 **파일 앱·브라우저·메신저로 설치할 때만** 막습니다. 알림판은 컴퓨터로 설치합니다.

1. 폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호**를 7번 눌러 개발자 옵션을 켜고, 설정 → 개발자 옵션 → **USB 디버깅** 켜기
2. USB 로 컴퓨터에 연결하고 폰에 뜨는 'USB 디버깅 허용'에서 허용
3. 컴퓨터: `adb install -r nursetodo-vX-noti.apk`
4. 앱 설정 › 다른 앱 알림 › 알림 접근 켜기 (컴퓨터로 깐 앱은 '제한된 설정'도 걸리지 않음)

알림판은 업데이트도 컴퓨터로 합니다. 여러 폰에 나눠 주는 Play 스토어 절차는 [docs/PLAY.md](docs/PLAY.md).

- 할 일·프리셋·설정은 넘어오지 않습니다(기기 안에만 저장하므로). 새로 입력해 주세요.
- 권한(알림, 다른 앱 위에 표시, 알림 접근)도 다시 허용합니다. 오늘 탭의 '잠금화면 설정 N개 남음'이 안내합니다.

## 빌드

요구사항: JDK 17+, Android SDK 35

```bash
./gradlew assembleRelease          # app/build/outputs/apk/{basic,noti}/release/app-*-release.apk
./gradlew testBasicDebugUnitTest   # 날짜·루틴·주입속도 로직, 저장 파일 변환 + Robolectric 렌더링/실행 테스트
```

- minSdk 26 (Android 8.0), targetSdk 36 (Play 신규 앱 조건)
- 깃허브 APK(release)는 debug 키로 서명합니다(기존 설치본 위에 덮어 설치되게). Play 용 AAB 는 `./gradlew bundleNotiRelease -Pplay` — 저장소 밖 업로드 키로 서명([docs/PLAY.md](docs/PLAY.md)).
- GitHub Actions 가 PR/main 푸시마다 테스트·lint 후 `nursetodo-apk` 아티팩트로 APK 를 올립니다.
- 폐쇄망 안에서 빌드하려면 사내 Maven 미러(google, mavenCentral 프록시)를 `settings.gradle.kts` 에 지정하세요.

## 구조

```
app/src/main/java/com/yuangunn/nursetodo/
├── NurseTodoApp.kt        앱 시작 시 저장소 로드, 카드·위젯 갱신
├── data/                  Task 모델(날짜·루틴 규칙), JSON 저장소, 날짜 포맷, 주입속도 계산(Infusion)
├── lock/                  잠금화면 카드, 체크 리시버, 잠금화면 위 패널, 빠른 설정 타일
├── widget/                홈 화면 위젯
└── ui/                    Compose 화면 (오늘 / 캘린더 / 계산기 / 설정 / 편집 시트)
```
