# Play 내부 테스트로 배포하기

알림판(다른 앱 알림 보기)은 폰에서 파일로 설치하면 Play 프로텍트가 막습니다. Play 스토어로 설치하면 막히지 않고, '제한된 설정'도 걸리지 않으며 자동으로 업데이트됩니다. 병동 폰에는 **내부 테스트**(최대 100명, 심사 없이 바로)로 나눠 줍니다. 개인 계정의 '12명·14일 비공개 테스트' 조건은 일반 공개(프로덕션)에만 붙고 내부 테스트에는 없습니다.

## 1. 개발자 계정 (한 번)
1. https://play.google.com/console/signup → 구글 계정으로 로그인 → **개인** 계정
2. 등록비 25달러(1회), 이름·주소, 신분증 본인 인증, 전화번호 인증. 안드로이드 폰의 Play Console 앱으로 기기 인증을 요구할 수 있음
3. 인증이 끝날 때까지(며칠 걸릴 수 있음) 기다림

## 2. 앱 만들기
- 앱 이름 `딱`, 기본 언어 **한국어**, 앱(게임 아님), 무료, 선언 두 개 체크
- 패키지 이름은 첫 업로드에서 정해짐: `com.ttaak.app`

## 3. 앱 콘텐츠(정책) 답안
| 항목 | 답 |
|---|---|
| 개인정보처리방침 | https://github.com/yuangunn/ttaak/blob/main/PRIVACY.md |
| 앱 액세스 | 모든 기능을 제한 없이 사용 가능(로그인 없음) |
| 광고 | 광고 없음 |
| 콘텐츠 등급 | 카테고리 '유틸리티, 생산성, 커뮤니케이션 또는 기타', 모든 질문 '아니요'(폭력·성적·도박·사용자 간 소통·위치 공유·디지털 구매 없음) |
| 타겟층 | 18세 이상 (업무용) |
| 데이터 보안 | 수집하는 데이터 없음, 공유하는 데이터 없음 (인터넷 권한 없음, 알림 내용은 기기 안에서만 표시) |
| 정부 앱 / 금융 기능 / 건강 | 아니요 / 없음 / 해당 없음 |
| 전체 화면 인텐트 | **알람**: 사용자가 맞춘 '몇 분 뒤' 알람이 울릴 때 잠금화면 위에 알람 화면(끄기 버튼)을 띄움 |
| 정확한 알람(USE_EXACT_ALARM) | 알람·타이머: 사용자가 맞춘 '몇 분 뒤' 알람(투약·항암 주입 종료 등)을 제시간에 울림 |
| 포그라운드 서비스 | `specialUse`(LockPageService): 화면이 켜질 때 잠금화면 위에 오늘 할 일 화면을 띄우려고 화면 켜짐 신호를 받는 상시 서비스. `mediaPlayback`(AlarmRingService): 알람음 재생(최대 10분) |

- 포그라운드 서비스 선언에서 시연 영상 링크를 요구하면 에뮬레이터 화면 녹화를 만들어 비공개(일부 공개) 링크로 올립니다.
- 정확한 알람은 Play 정책상 '알람·타이머가 핵심 기능인 앱'에 한정됩니다. 내부 테스트는 심사를 거의 받지 않지만, 나중에 일반 공개하면 거절될 수 있습니다. 그때는 `SCHEDULE_EXACT_ALARM`(사용자가 '알람 및 리마인더'를 허용)으로 바꿉니다.

## 4. 내부 테스트 출시
1. 테스트 → **내부 테스트** → 테스터: 이메일 목록 만들기(테스터의 구글 계정)
2. 새 버전 만들기 → **Play 앱 서명** 사용(기본값, 구글이 앱 서명 키를 보관) → AAB 업로드
   - AAB 만들기: `./gradlew bundleNotiRelease -Pplay` → `app/build/outputs/bundle/notiRelease/app-noti-release.aab`
   - `-Pplay` 는 저장소 밖 업로드 키(`~/.gradle/gradle.properties` 의 `ttaakUploadStore`·`ttaakUploadPassword`)로 서명합니다. 업데이트 때마다 `versionCode` 를 올립니다.
3. 버전 이름·출시 노트 → 검토 → 내부 테스트로 출시
4. 테스터 탭의 **참여 링크**를 테스터에게 보냄 → 링크에서 수락 → Play 스토어에서 '딱' 설치

## 5. 스토어 등록정보 (요구할 때)
- 간단한 설명: `화면을 켜면 잠금화면 위에 오늘 할 일이 먼저. 체크·추가·알람을 잠금 해제 없이.`
- 자세한 설명:
  > 화면을 켜면 잠금화면 위에 오늘 할 일이 먼저 뜹니다. 동그라미를 눌러 체크하고, 바로 적어 추가하고, '몇 분 뒤' 알람을 맞추세요. 잠금을 풀 필요가 없습니다.
  >
  > - 팀즈·문자 같은 다른 앱 알림도 할 일 아래에 최근 3개까지(고른 앱만)
  > - 바로가기: 계산기, 알람, 할 일 추가, 자주 쓰는 앱
  > - 매일·요일 루틴, D-day, 홈 화면 위젯
  > - 전화가 오면 수신 화면을 가리지 않음
  > - 계정·인터넷 없음. 모든 데이터는 이 폰 안에만
- 앱 아이콘 512×512, 그래픽 이미지 1024×500: [`docs/play/icon-512.png`](play/icon-512.png), [`docs/play/feature-1024x500.png`](play/feature-1024x500.png)
- 휴대전화 스크린샷 2장 이상: 긴 변이 짧은 변의 2배를 넘으면 안 됨(1080×2400 은 1080×2160 으로 자름)

## 주의
- Play 설치본은 구글 서명이라 **깃허브 APK 와 서명이 달라 덮어 설치되지 않습니다.** 깃허브 설치본을 지우고 Play 에서 설치해야 하고, 할 일은 새로 입력해야 합니다(기기 안에만 저장하므로).
- 업로드 키(`~/ttaak-play/ttaak-upload.jks`)와 비밀번호(`~/.gradle/gradle.properties`)는 백업해 두세요. 잃어버려도 Play Console 에서 업로드 키 재설정을 요청할 수 있습니다.
