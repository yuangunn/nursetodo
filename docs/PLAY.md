# Play 스토어 출시하기

알림판(다른 앱 알림 보기)은 폰에서 파일로 설치하면 Play 프로텍트가 막습니다. 막는 대상은 브라우저·메신저·파일 앱으로 받은 설치이고, Play 스토어 설치는 아닙니다. Play 설치본은 자동으로 업데이트됩니다. '제한된 설정'도 스토어 밖에서 깐 앱에 걸리는 것이라 Play 설치본에는 걸리지 않을 것으로 보지만, 첫 테스터 폰에서 알림 접근이 켜지는지 확인합니다.

2023-11-13 이후 만든 개인 계정은 **비공개 테스트(테스터 12명 이상, 14일 연속 참여)**를 마쳐야 일반 공개(프로덕션)를 신청할 수 있습니다. 병동에 나눠 주기만 할 거라면 내부 테스트(최대 100명)로도 되지만, 내부 테스트 참여자는 비공개 테스트를 받을 수 없습니다.

## 1. 개발자 계정 (한 번)
1. https://play.google.com/console/signup → 구글 계정으로 로그인 → **개인** 계정
2. 등록비 25달러(1회), 이름·주소, 신분증 본인 인증, 연락처 전화번호·이메일 인증
3. 새 개인 계정은 실제 안드로이드 폰 인증도 요구할 수 있습니다: 폰에 'Google Play Console' 앱을 깔고 같은 구글 계정으로 로그인
4. 대시보드에 남은 인증이 없어야 앱을 만들 수 있습니다(며칠 걸릴 수 있음)

## 2. 앱 만들기
- 앱 이름 `널스투두 - 간호사 잠금화면 할 일`(Play 제목 30자 이내, 검색에 걸리게 설명을 붙임), 기본 언어 **한국어**, 앱(게임 아님), 무료, 선언 두 개 체크
- 스토어 설정: 앱 카테고리 **생산성**, 태그 '할 일 목록'. 널스투두는 **간호사를 위한 잠금화면 기반 할 일(To-Do) 앱**이고, 알람·알림 보기·계산기는 그에 딸린 기능입니다
- 패키지 이름은 첫 업로드에서 정해지고 다시 못 바꿈: `com.yuangunn.nursetodo` (v1.6.0 에 `com.ttaak.app` 에서 바꿈)

## 3. 앱 콘텐츠(정책) 답안
| 항목 | 답 |
|---|---|
| 개인정보처리방침 | https://github.com/yuangunn/nursetodo/blob/main/PRIVACY.md |
| 앱 액세스 | 모든 기능을 제한 없이 사용 가능(로그인 없음) |
| 광고 | 광고 없음 |
| 콘텐츠 등급 | 카테고리 '유틸리티, 생산성, 커뮤니케이션 또는 기타', 모든 질문 '아니요'(폭력·성적·도박·사용자 간 소통·위치 공유·디지털 구매 없음) |
| 타겟층 | 18세 이상 (업무용) |
| 데이터 보안 | 수집하는 데이터 없음, 공유하는 데이터 없음 (인터넷 권한 없음, 알림 내용은 기기 안에서만 표시·키워드 비교. 기기 안에서만 처리하는 데이터는 '수집'이 아님) |
| 정부 앱 / 금융 기능 / 건강 | 아니요 / 없음 / 해당 없음 |
| 전체 화면 인텐트 | **알람·전화가 핵심 기능인 앱이 아님**(할 일 앱). 쓰는 곳: 사용자가 맞춘 '몇 분 뒤' 알람이 울릴 때 잠금화면 위에 알람 화면(끄기 버튼)을 띄움 |
| 정확한 알람(`SCHEDULE_EXACT_ALARM`) | 사용자가 맞춘 '몇 분 뒤'·'몇 시에' 알람(투약·항암 주입 종료 등)과 교대 프리셋의 근무 루틴 알림을 제시간에 울림. 사용자가 '알람 및 리마인더'를 허용해야 함 |
| 포그라운드 서비스 | `specialUse`(LockPageService): 화면이 켜질 때 잠금화면 위에 오늘 할 일 화면을 띄우려고 화면 켜짐 신호를 받는 상시 서비스. `mediaPlayback`(AlarmRingService): 알람음 재생(최대 10분). 시연 영상 링크(준비물) |

- 전체 화면 인텐트를 '알람 앱'이라고 답하면 `USE_EXACT_ALARM` 처럼 핵심 기능이 아니라는 이유로 거절될 수 있습니다. 할 일 앱이라고 답하면 구글이 이 권한을 기본으로 주지 않을 뿐이고, 앱의 설정 › 알람에 '알람 화면이 꺼져 있어요 → 허용' 줄이 뜹니다. 허용 전에는 알람이 소리와 알림으로만 울립니다.
- `USE_EXACT_ALARM`(설치 때 자동 허용)은 Play 정책상 알람·캘린더가 핵심 기능인 앱만 쓸 수 있어서 v1.6.1 에서 뺐습니다. 안드로이드 14+ 는 새로 깔면 '알람 및 리마인더'가 꺼져 있어, 앱이 오늘 탭 안내와 알람 입력 칸에서 허용을 받습니다. 허용 전에 맞춘 알람은 늦게 울릴 수 있고, 허용하면 제시간으로 다시 맞춥니다.

## 4. 비공개 테스트 → 일반 공개
1. 테스트 → **비공개 테스트** → 트랙 → 국가 **대한민국** → 테스터: 이메일 목록 만들기(테스터의 구글 계정)
   - 14일을 채우지 못하고 나간 테스터는 세지 않으므로 12명보다 몇 명 더 받습니다.
   - 같은 사람을 내부 테스트에 먼저 넣지 않습니다(내부 테스트 참여자는 비공개 테스트를 받을 수 없음).
2. 새 버전 만들기 → **Play 앱 서명** 사용(기본값, 구글이 앱 서명 키를 보관) → AAB 업로드
   - AAB 만들기: `./gradlew bundleNotiRelease -Pplay` → `app/build/outputs/bundle/notiRelease/app-noti-release.aab`
   - `-Pplay` 는 저장소 밖 업로드 키(`~/.gradle/gradle.properties` 의 `nursetodoUploadStore`·`nursetodoUploadPassword`)로 서명합니다. 업데이트 때마다 `versionCode` 를 올립니다.
3. 버전 이름·출시 노트 → 검토 → 비공개 테스트로 출시(구글 검토를 거침)
4. 테스터 탭의 **참여 링크**를 테스터에게 보냄 → 링크에서 수락 → Play 스토어에서 '널스투두' 설치. 테스터 폰은 구글 계정으로 Play 스토어에 들어갈 수 있어야 합니다.
5. 14일 뒤 대시보드 → **프로덕션 액세스 신청**: 비공개 테스트(테스터 모집이 쉬웠는지, 기능을 다 써 봤는지, 받은 의견), 앱(대상·가치·첫해 예상 설치 수), 출시 준비(테스트로 바꾼 점, 준비됐다고 본 근거)를 적습니다. 검토는 보통 7일 이내이고, 테스터 수나 참여가 모자라면 비공개 테스트를 더 해야 합니다.
6. 승인되면 프로덕션 → 새 버전으로 출시합니다.

## 5. 스토어 등록정보
- 간단한 설명: `간호사를 위한 잠금화면 할 일 앱. 화면을 켜면 오늘 할 일이 먼저, 잠금 해제 없이 체크·추가.`
- 자세한 설명:
  > 널스투두(널스 투두, 너스 투두)는 간호사를 위한 잠금화면 기반 할 일(To-Do) 앱입니다. 화면을 켜면 잠금화면 위에 오늘 할 일이 먼저 뜹니다. 동그라미를 눌러 체크하고, 바로 적어 추가하고, '몇 분 뒤' 알람을 맞추세요. 다 보고 나면 위로 밀어 잠금을 풉니다.
  >
  > - 교대 프리셋: '근무 교대 받았습니다'를 누르면 Day·Evening·Night 할 일 목록으로 바뀌고, 못 끝낸 일은 가져올지 고르기 (10초 되돌리기, 두 칸 들여 쓰면 하위 항목)
  > - 근무 루틴 알림: '07:00 정규 라운딩'처럼 시각을 붙이면 근무를 받은 폰에서만 조용히 진동과 팝업으로, 30분 넘게 안 한 일은 미체크로 빨갛게
  > - 포켓북: 진단명·수술명별로 사정할 때 볼 것을 적어 두고 잠금화면에서 펼쳐 보며 체크 (붙여넣기·엑셀 표로 만들기)
  > - 팀즈·문자 같은 다른 앱 알림을 앱 아이콘과 개수로, 누르면 알림 목록 (고른 앱만)
  > - 키워드 알림: 문자·팀즈 알림에 '배정되었습니다' 같은 낱말이 오면 근무를 받은 폰에서 진동과 팝업, 확인할 때까지 잠금화면 맨 위 붉은 카드로 (확인 · 열기 · 할 일로 추가)
  > - 항암 주입속도 계산기: 시간·분 두 칸, 끝나는 시각과 알람 맞추기, 상한을 넘으면 주황 경고
  > - 바로가기: 항암계산기, 알람(여러 개, 5분 뒤 다시 울림), 캘린더, 할 일 추가, 자주 쓰는 앱
  > - 매일·요일 루틴, 홈 화면 위젯, 다크 모드
  > - 전화가 오면 수신 화면을 가리지 않음
  > - 계정·인터넷 없음. 모든 데이터는 이 폰 안에만
- 앱 아이콘·그래픽 이미지·스크린샷: 준비물 표의 `docs/play/` 파일. 스크린샷은 긴 변이 짧은 변의 2배를 넘으면 안 되어 1080×2400 화면을 시그니처 남색 바탕 1240×2400 가운데에 얹었습니다. 예시 할 일로 에뮬레이터에서 찍었습니다.

## 주의
- Play 설치본은 구글 서명이라 **깃허브 APK 와 서명이 달라 덮어 설치되지 않습니다.** 깃허브 설치본(옛 이름 딱 포함)을 지우고 Play 에서 설치해야 하고, 할 일은 새로 입력해야 합니다(기기 안에만 저장하므로).
- 업로드 키(`~/ttaak-play/ttaak-upload.jks`)와 비밀번호(`~/.gradle/gradle.properties`)는 백업해 두세요. 잃어버려도 Play Console 에서 업로드 키 재설정을 요청할 수 있습니다.
